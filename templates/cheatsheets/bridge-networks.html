Bridge Networks

Common server-side networks that clients can opt into from the client form.

One shared LAN

Clients can opt into routing one server-side LAN through the VPN.

Example:

192.168.50.0/24
Multiple shared LANs

Clients get one checkbox per network and can choose which LANs to route through the VPN.

Example:

192.168.50.0/24, 10.20.0.0/16
Small services subnet

Clients route only a narrow subnet for shared services instead of an entire site LAN.

Example:

192.168.50.0/28
Avoid common home ranges

Prefer less common ranges when possible, because overlapping LANs can break local access for users.

Example:

10.240.10.0/24

More details: WireGuard overview
